# Conector do Crop Steering

Liga este Home Assistant ao Cropilot. Com ele, o Cropilot lê os sensores de temperatura e umidade e comanda o
ar-condicionado, o desumidificador e as tomadas que você liberar no Cropilot.

Ele só abre conexões de saída, com HTTPS, até o Cropilot, e não abre nenhuma porta no computador nem na sua rede.
Use um Home Assistant só do cultivo: uma tomada liberada pode ser ligada e desligada pelo Cropilot.
Para parear, gere o código em Perfil › Conexões, no Cropilot, e siga a aba Documentação depois de instalar.
